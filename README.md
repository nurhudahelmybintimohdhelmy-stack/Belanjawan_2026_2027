# Dashboard Belanjawan 2026 vs 2027

Dashboard interaktif (satu fail `index.html`, tanpa proses build) membandingkan peruntukan Belanjawan 2026 dan 2027 mengikut sektor, kementerian dan program utama.

## Terbitkan di GitHub Pages
1. Cipta repo baharu di GitHub, kemudian muat naik `index.html`, `README.md` dan `.nojekyll`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Laman akan hidup di `https://<nama-pengguna>.github.io/<nama-repo>/`.

## Data
Disusun dalam `index.html` (pemboleh ubah `M` untuk kementerian, `SECTORS` untuk pengelompokan sektor, `PR` untuk program). Kemas kini di situ.
Sumber: Ucapan Belanjawan 2026, ucapan Belanjawan 2027, laporan Bernama/The Edge/The Sun/FMT, dan penjejak Malaysia4U (anggaran MOF).
Nota: peruntukan Kementerian Kewangan 2027 (RM71.5b berbanding RM47.0b) perlu disahkan daripada buku Anggaran Perbelanjaan MOF.
